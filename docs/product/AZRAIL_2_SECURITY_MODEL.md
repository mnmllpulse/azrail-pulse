# AZRAIL 2.0 — модель безопасности

База `1.5.0-rc.63`. Этот документ фиксирует действующие границы и то, что сценарий 2.0 ещё не имеет права ослабить.

## Действующие границы

- Вход: почта через Cloudflare Access. Режим `AUTH_MODE=oidc`. Запасной ключ воркера снят. Сессия — HttpOnly cookie.
- Платный вывод моделей выключен флагом бесплатного плана. Каталог не является разрешением на вызов.
- Суточные потолки: чат 200, генерация 500. Это резерв, не показ выдуманного остатка. Если остаток не прочитан, лицо говорит потолок.
- Бюджет миссии: 0.10.
- Повтор картинки: тот же ключ и то же тело. Другое тело при живом ключе не отправляется.
- Внешний эффект с неясным исходом не повторяется автоматически. Резерв неудачного вызова держится сутки. Истечение срока не доказывает, что эффект не случился.
- Публичная страница `/s/:id/` — экранированный HTML студии. Редакторский скрипт в скачивание не входит. Для `/s/` своя политика страницы, её не затирает общая оболочка.
- Предпросмотр страницы в потоке Web Studio не получает `allow-same-origin` вместе со скриптами. Замер телефона идёт отдельным кадром без скриптов.
- Чужой адрес для референса: только HTTPS, только после входа, с отсечением запроса во внутреннюю сеть. Текст конкурента не копируется.
- Секреты не пишутся в исходники, в ZIP, в память модели и в ответ чата.
- Зритель проекта не снимает копию проекта.
- Подтверждение нужно на удаление и на иные уже закрытые опасные действия. Правка текста страницы подтверждения не требует. Голос не должен сам разрешать необратимое действие.

## Что сценарий требует и чего ещё нет

- Отдельный Secret Broker как единственная дверь секрета в песочницу: путь есть у песочницы, единого брокера на все инструменты нет.
- ABAC рядом с текущими ролями: не выделен отдельным слоем.
- Журнал каждого вызова инструмента до исполнения: есть журнал миссии и решения, не полный шлюз инструментов.
- Изоляция арендаторов как многоорганизационная модель: рабочий контур — один владелец и его доступ. Смешивать проекты и чужие данные всё равно нельзя.
- Жёсткая остановка дорогой миссии по лимиту агента и провайдера: есть бюджет миссии и суточные потолки, нет раздельных кошельков на агента.

## Запреты на время переноса

- Не ослаблять проверку прав.
- Не класть секрет в промпт.
- Не давать агенту расширять собственные права.
- Не выполнять произвольную команду вне уже существующей песочницы.
- Не применять миграции к рабочей базе без отдельного разрешения.
- Не выкладывать `wrangler.production.json`.
- Не включать маски, платную съёмку и увеличение ролика обходным провайдером.
- Не объявлять интеграцию готовой без реального connection test.
