Status: planned (принято владельцем, реализация после текущих задач)

Но чтобы это стало не просто работающим приложением, а полноценным продуктом, который можно продавать и потенциально выгодно продать как бизнес, нужно закрыть ещё несколько критических направлений.
Что ещё необходимо AZRAIL PULSE
1. Надёжный AI-разработчик
Критический приоритет
Недостаточно, чтобы AI просто генерировал код. Он должен самостоятельно доводить задачу до результата.
- Читать существующий проект.
- Понимать структуру репозитория.
- Создавать и изменять файлы.
- Выполнять команды.
- Получать реальные логи.
- Анализировать ошибки сборки.
- Исправлять ошибки.
- Повторно запускать сборку.
- Проверять работающий результат.
- Не сообщать об успехе, если результат не проверен.
Нужен полноценный цикл:
(схема цикла: задача → анализ проекта → план → правка файлов → Build → при ошибке анализ и исправление → Preview → проверка → отчёт)

2. Desktop Agent — полноценный исполнитель
Он должен быть не просто мостом, а отдельным продуктовым компонентом.
- Windows Installer.
- Автоматическое обновление.
- Подключение и отключение от аккаунта.
- Защищённая связь с Cloudflare.
- Управление процессами.
- Запуск приложений.
- Terminal.
- Работа с файловой системой.
- Управление разрешениями.
- Восстановление после обрыва соединения.
В дальнейшем можно добавить macOS и Linux.
3. Профессиональный Sandbox
Это одно из наиболее важных преимуществ AI IDE.

Нужны:
- изолированная среда выполнения;
- Terminal;
- файловая система проекта;
- Code Editor;
- Live Preview;
- Build;
- Debug;
- управление зависимостями;
- сохранение проекта;
- восстановление контрольной точки;
- импорт ZIP;
- экспорт ZIP;
- управление портами;
- ограничение CPU, RAM и времени выполнения.
В текущем репозитории уже есть Sandbox-архитектура, но наличие адаптера ещё не доказывает полноценную работу всех этих функций в реальном окружении.
4. Безопасность коммерческого уровня
Обязательно перед публичным запуском
Поскольку AZRAIL будет управлять компьютером клиента, безопасность должна быть встроена в архитектуру.
Механизм	Требование
User Isolation	Изоляция аккаунтов и проектов
Permission Engine	Контроль разрешённых действий
Secrets Vault	Защищённое хранение API-токенов
Sandbox Isolation	Изоляция запуска кода
Audit Logs	История действий AI
Kill Switch	Немедленная остановка агента
Rate Limiting	Защита от злоупотреблений
Data Encryption	Шифрование чувствительных данных
Prompt Injection Defense	Защита от вредоносных инструкций из файлов и сайтов
Rollback	Восстановление файлов и предыдущего состояния проекта

Особенно важно: AI не должен иметь постоянный unrestricted-доступ к компьютеру пользователя. У каждого инструмента должны быть определены права.
5. GitHub и Cloudflare — не просто кнопки
Нужны полноценные интеграции.
GitHub
- OAuth / GitHub App.
- Список репозиториев.
- Клонирование.
- Commit.
- Push / Pull.
- Branch.
- Pull Request.
- Git Diff.
- Конфликты слияния.
- Управление репозиторием.
- Создание публичного или приватного репозитория с подтверждением.
Cloudflare
- Подключение аккаунта клиента.
- Выбор Worker или Pages проекта.
- Выбор домена.
- Управление переменными окружения.
- Build.
- Deploy.
- Просмотр логов.
- Rollback.
- Проверка статуса Deployment.
- Получение URL опубликованного приложения.
Необходимо разделить расходы: клиент может использовать свои Cloudflare credentials и ресурсы, а AZRAIL взимать плату за собственную платформу.

7. Уникальное преимущество AZRAIL PULSE
Вот что я бы сделал основным отличием от Cursor.
AZRAIL UNIVERSAL EXECUTION

Один чат. Любая задача. Реальное выполнение.

- Создание приложений
- Разработка сайтов
- Работа с локальными программами
- Управление проектами
- GitHub автоматизация
- Cloudflare Deployment
- Обработка файлов
- В будущем — дополнительные рабочие процессы через Plugins

Главное — не продавать идею «у нас много моделей».

Продавать нужно результат: пользователь поставил задачу — AZRAIL её выполнил.

- Build Verification.
- Sandbox Verification.

Я бы сосредоточился на пяти вещах:
1. Универсальный чат, который действительно выполняет задачи.
2. Desktop Agent, который безопасно управляет компьютером пользователя.
3. Профессиональный Sandbox с Terminal и Live Preview.
4. GitHub + Cloudflare автоматизация.

И самое главное: не начинать всё с нуля. У AZRAIL PULSE уже есть существующая кодовая база, которую нужно использовать и довести до проверенного состояния.
