# AZRAIL 2.0 — матрица способностей

Статусы: `IMPLEMENTED` — есть рабочий путь. `LIMITED` — путь есть, и у него записанное ограничение. `DISABLED` — сознательно закрыто. `PLANNED` — есть в сценарии 2.0 и нет в текущем поведении. `VERIFIED` в этой матрице не используется: официальная готовность релиза не подтверждена.

Каталог моделей: 268 уникальных имён, из них 74 в бесплатном контуре и 194 платных. Присутствие в каталоге не разрешает платный вызов. `AZRAIL_FORCE_FREE` остаётся включённым.

## Опыт

| Способность | Статус | Где | Ограничение |
|---|---|---|---|
| Чат как поручение | IMPLEMENTED | `ui/app.ts`, `src/lib/assignment-plan.ts`, `src/lib/intent-contract.ts` | До четырёх частей. Полоса пишет, кто выбран и нужно ли подтверждение. Это правило по фразе, не отдельная модель |
| Полоса: повтор одной части, версии, скачивание | IMPLEMENTED | полоса чата | Повтор картинки досылает зависшее тело тем же ключом |
| Ход задачи до статуса «готово» | IMPLEMENTED | `settleMission` в `ui/app.ts` | «Выполняю задачу» не считается результатом |
| Голос по умолчанию «Серый» | LIMITED | лицо чата | Ключ озвучки не установлен |
| Экран агентов, знаний, интеграций | PLANNED | — | Не строить пустой раздел |
| Голосовой ввод миссии | PLANNED | `src/unified/voice.ts` | Голос не подтверждает необратимое действие |

## Студии

Имена студий остаются английскими.

| Студия | Статус | Ограничение |
|---|---|---|
| Web Studio | LIMITED | Страница собирается миссией и публикуется на `/s/:id/` текущего воркера на 90 дней. Это не отдельный хостинг страниц |
| Image Studio | LIMITED | Flux klein 9b / 4b. Варианты 2–4. Своя картинка задаёт вид. Маска и удаление фона закрыты |
| Music Studio | LIMITED | Локальная сборка и плеер. Внешняя модель ждёт секрет воркера и не вызывается без него |
| Video Studio | LIMITED | Кадры и WebM на экране. Внешний видеопровайдер не подключён. Таймлайн не доказывает генерацию ролика |
| Audio Lab | LIMITED | Измерения на устройстве |
| Ableton Lab | LIMITED | Разбор набора, не замена Ableton Live |
| Data Studio | LIMITED | Разбор на устройстве |
| Ledger Studio | LIMITED | Учёт расходов. Несверка счёта не объявляется нулевой |
| Pulse Lab | LIMITED | Диагностика без синтетических платных вызовов |
| Prose Studio | IMPLEMENTED | Текст остаётся текстом. Фраза «Для картинки» кладётся в поле Image Studio |
| Architecture / Development / Creative / Market | PLANNED | В рабочем манифесте их нет. Старые экраны лежат в `references/legacy` |

## Агенты и миссии

| Способность | Статус | Ограничение |
|---|---|---|
| Реестр девяти агентов | IMPLEMENTED | `registered`, не «онлайн» |
| Metatron: старт, пауза, продолжение, отмена, остановка, checkpoints | LIMITED | Граф `explicit`, только если у каждого шага записаны рёбра. Иначе по-прежнему `derived-linear` |
| Проверка графа на цикл и параллельные группы | IMPLEMENTED | `src/lib/mission-graph.ts`. Это библиотека, не сохранённый планировщиком DAG |
| Двенадцать ролей сценария и оценка качества агента | PLANNED | Пустой класс агента не регистрируется |
| Динамическое добавление узлов во время миссии | PLANNED | Пока нет безопасных версий графа |

## Модели и инструменты

| Способность | Статус | Ограничение |
|---|---|---|
| Реестр и маршрутизатор | IMPLEMENTED | Выбор объясняется. Выдуманный рейтинг запрещён |
