# Единый чат

Status: current

Состояние на 20 ноября 2026. Исходники: `ui/app.ts`, `ui/assignment.ts`, `ui/planner.ts`, `ui/draw-intent.ts`, `ui/chat-markdown.ts`, `ui/attachment-manager.ts`, `src/agents/answer-agent.ts`, `src/lib/answer-style.ts`.

## Принцип

Один чат вместо отдельных студий. Фраза определяет действие, студии работают внутри и на главном экране не показаны (см. `STUDIO_ARCHITECTURE_RU.md`).

| Фраза | Результат |
|---|---|
| Вопрос, «объясни», «опиши», «промпт этой картинки» | ответ модели (разговор) |
| «нарисуй …», «изобрази …» | картинка (два варианта, размер выбирается) |
| «рисуй», «давай нарисуй это» без описания | рисует прошлый промпт: блок кода из прошлого ответа или прошлое сообщение пользователя |
| «измени…», «в таком же стиле» с приложенной картинкой | правка по образцу, режим edit |
| «сделай сайт / страницу», «pdf / docx / xlsx / pptx», «схема» | страница, файл, схема в чате |
| фразы про компьютер | задача локальному агенту (`docs/LOCAL_AGENT.md`) |

Правила распознавания лежат в `ui/assignment.ts` (`readAssignment`) и `ui/draw-intent.ts` (`drawRequest`). Вопросительная фраза, условное предложение и фраза про промпт, описание или подпись к картинке остаются разговором. Планировщик `/api/plan` (LLM-классификатор) вызывается только для рабочих запросов.

## Отправка и вложения

- Сообщение уходит сразу: поле очищается до запроса, вложения предзагружаются при добавлении, а не при отправке.
- В ленте картинка отображается отдельным блоком над текстом сообщения.
- Картинка из скрепки загружается в R2 (если выбран проект), чат читает её через `env.AI.toMarkdown`. Вложение без ключа хранилища на сервер не уходит (раньше давало «Некорректное вложение»). Подробнее — `ATTACHMENTS_RU.md`.
- Ответ модели ждётся до 55 секунд; при таймауте повтор запрещён (возможен дубль списания), чат пишет понятное сообщение.
- Лимиты: чат 200 и генерация 500 в сутки; остаток читает `/api/limits` без списания, нейроны — `/api/studio/budget`.

## Стиль ответов

Системный промпт агента (`answer-style.ts`) задаёт структуру: вступление, разделы `### N. Название`, короткая категория курсивом, блок «Проверка», цитата `>`, разделитель `---`, финальный вопрос. Рендерер `ui/chat-markdown.ts` поддерживает заголовки, списки, цитаты, разделители и inline-код. Ответ отвечает на языке пользователя. Фразу про студии промпт не использует.

## Модели и уровень усилий

Кнопка под полем ввода открывает меню моделей и уровень усилий (низкий / средний / высокий / максимум). Уровень влияет на глубину ответа, бюджет токенов и выбор модели в чате и миссиях. Модели и автовыбор — `MODELS_RU.md`.

## Профиль

Ник задаётся вручную в «Аккаунт и профиль» (поле «Ник», сброс к значению по умолчанию), почта в интерфейсе не показывается; можно загрузить своё фото профиля. Сервер хранит ник в `src/unified/nickname.ts`.

## Проверка работоспособности

`GET /health/live` — JSON с версией сборки; `scripts/staging-auto-health.mjs` проверяет его после выкладки staging.
