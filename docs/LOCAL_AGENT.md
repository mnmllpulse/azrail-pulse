# Локальный агент

Status: active

Агент даёт AZRAIL доступ к одной папке на твоём компьютере. Без него воркер в облаке не видит твои файлы.

## Принципы

| Правило | Как соблюдается |
|---|---|
| Выключен по умолчанию | Состояния нет, пока владелец не нажмёт «Включить» в настройках |
| Короткая сессия | Ключ действует 1 час, повторное включение отзывает прежний ключ |
| Одна папка | Агент работает от `AZRAIL_ROOT`, пути вне неё и симлинки наружу отклоняются |
| Секреты закрыты | `.env*`, `.dev.vars`, `.git`, `.ssh`, `node_modules`, `*.pem`, `*.key` не читаются и не пишутся (сервер и агент проверяют независимо) |
| Запись по подтверждению | `write` ждёт «Разрешить» владельца; `read` и `list` идут сразу |
| Команд нет | Выполнение команд не реализовано намеренно |
| Только владелец | Все владельческие маршруты требуют роль admin |

## Запуск

1. Настройки → «Агент на компьютере» → «Включить на 1 час».
2. Скопируй показанные строки в PowerShell, указав свою папку в `AZRAIL_ROOT`.
3. Агент пишет в консоль каждое действие. Остановка: Ctrl+C или «Выключить».

## API

Владелец: `GET /api/agent/status`, `POST /api/agent/enable`, `POST /api/agent/disable`, `POST /api/agent/jobs`, `GET /api/agent/jobs/:id`, `POST /api/agent/jobs/:id/approve|reject`.
Агент (Bearer `azagent_…`): `GET /api/agent/poll`, `POST /api/agent/jobs/:id/result`.

Очередь хранится в SQLite объекта Orchestrator (экземпляр `local-agent`), миграции D1 не нужны. Задачи живут 15 минут.

## Ограничения

- Чат пока не ставит задачи сам: они создаются из настроек.
- Чтение — до 200 000 байт, запись — до 200 000 символов.
- Выключатель `AZRAIL_SWITCH_TOOLS=off` закрывает все маршруты агента.
