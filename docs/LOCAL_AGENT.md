# Локальный агент

Status: active

Агент даёт AZRAIL доступ к одной папке на твоём компьютере. Без него воркер в облаке не видит твои файлы.

## Принципы

| Правило | Как соблюдается |
|---|---|
| Выключен по умолчанию | Состояния нет, пока владелец не нажмёт «Включить» в настройках |
| Короткая сессия | Ключ действует 1 час, повторное включение отзывает прежний ключ |
| Одна папка | Агент работает от `AZRAIL_ROOT`, пути вне неё и симлинки наружу отклоняются |
| Секреты закрыты | `.env*`, `.dev.vars`, `.git`, `.ssh`, `node_modules`, `*.pem`, `*.key` не читаются и не пишутся (сервер и агент проверяют независимо) |
| Запись по подтверждению | `write` ждёт «Разрешить» владельца; `read` и `list` идут сразу |
| Команды из белого списка | `run` принимает только идентификатор: `git_status`, `git_diff`, `git_log`, `node_version`, `npm_test`, `npm_build`, `npm_lint`, `npm_typecheck`. Аргументы зафиксированы в агенте, оболочки нет, лимит 2 минуты, каждый запуск ждёт «Разрешить». Дочерний процесс не получает `AZRAIL_*`. Произвольных команд нет |
| Страницы под твоими входами | `web` читает страницу в браузере компьютера (Chrome через playwright) и идёт сразу, как `read`. Только чтение: кликов и ввода нет. Адреса проверяются на сервере и в агенте одинаково: только публичные http(s), без логина в адресе, портов, внутренних имён и частных IP; редирект и подзапросы на внутренние адреса блокируются |
| Только владелец | Все владельческие маршруты требуют роль admin |

## Запуск

1. Настройки → «Агент на компьютере» → «Включить на 1 час».
2. Скопируй показанные строки в PowerShell, указав свою папку в `AZRAIL_ROOT`.
3. Агент пишет в консоль каждое действие. Остановка: Ctrl+C или «Выключить».

## API

Владелец: `GET /api/agent/status`, `POST /api/agent/enable`, `POST /api/agent/disable`, `POST /api/agent/jobs`, `GET /api/agent/jobs/:id`, `POST /api/agent/jobs/:id/approve|reject`.
Агент (Bearer `azagent_…`): `GET /api/agent/poll`, `POST /api/agent/jobs/:id/result`.

Очередь хранится в SQLite объекта Orchestrator (экземпляр `local-agent`), миграции D1 не нужны. Задачи живут 15 минут.

## Ограничения

- Из чата задачи ставятся только по явной фразе с «на компьютере» или «в папке»: «прочитай src/a.ts на компьютере», «покажи файлы в src на компьютере», «запиши в notes/a.txt на компьютере:» и текст со следующей строки. Запись и запуск команд ждут ответа «разреши» или «отклони». Фразы для команд: «запусти тесты на компьютере», «собери проект на компьютере», «покажи git status на компьютере». Если агент выключен, чат говорит об этом и ничего не ставит.
- Место распознаётся и в разговорной форме: «на компьютере/компе/пк/ноуте», «на локальном компе», «на моей машине», «локально». Глаголы запуска: запусти, прогони, выполни, сделай, проведи, проверь («сделай тест на локальном компе» = npm test).
- Просьба про компьютер, которую чат не распознал («запусти докер на компе»), получает подсказку со списком фраз, а не ответ модели «доступа нет». Запрос к агенту при этом не создаётся.
- Цикл исправления: «исправь ошибки сборки на компьютере» или «почини тесты на компьютере». Чат один раз просит «разреши» (принимаются также «ок», «да», кавычки). После этого до 3 раундов: запуск → разбор лога → правка → повторный запуск. Правятся только файлы, названные в логе и прочитанные агентом, не больше 3 за раунд; закрытые пути агент отклоняет сам. Перед записью оригинал копируется в `.azrail-backup/rN/` (каталог в `.gitignore`). Успех — только код выхода 0; при исчерпании раундов или невалидном ответе модели цикл останавливается и показывает хвост лога. Согласие живёт в памяти вкладки и не переживает перезагрузку страницы.
- Откат: «откати правки на компьютере» показывает список файлов последнего цикла и после «разреши» возвращает каждый файл из самой ранней копии в `.azrail-backup/`. Список файлов хранится в localStorage браузера (`azrail.fixRestore.v1`); в другом браузере откат недоступен, копии при этом лежат в папке проекта. Если копия не записалась, файл не меняется.
- Сквозной тест `tests/local-agent-e2e.test.ts`: HTTP-сервер на логике `src/lib/local-agent.ts` и настоящий `azrail-agent.mjs` во временной папке с git-репозиторием. Проверяет чтение, запись с подтверждением, отклонённую запись (файла нет), команды `node_version` и `git_status`, закрытые пути, вставленные в обход сервера (агент сам отказывает), завершение агента после конца сессии. Не проверяет Cloudflare, браузер и модель.
- Панель «Терминал» (кнопка «Код» → вкладка «Терминал»): выбор «Компьютер» запускает команду из белого списка через агента, перед запуском показывает «Разрешить / Отклонить»; выбор «Песочница: тесты» вызывает `/api/trial/sandbox`. Журнал хранится только в открытой вкладке.
- Запуск: после «Включить на 1 час» показывается панель «Запуск на компьютере»: поле папки (пусто = текущая папка PowerShell через `(Get-Location).Path`), готовая команда и кнопка «Скопировать команду». Ключ показывается один раз; после обновления страницы нужно выключить и включить агента заново. Агент в каждом запросе передаёт свою папку в заголовке `X-Agent-Root`, статус возвращает её (`root`), интерфейс показывает «Агент подключён, папка: …» и сам обновляется каждые 3 с, пока агент включён. Абсолютный путь внутри этой папки в форме задачи пересчитывается в относительный, путь вне неё отклоняется до отправки.
- Терминал в «Живом экране» — не PowerShell: цель «Компьютер» запускает только команды из выпадающего списка (белый список агента), произвольный текст вставить нельзя. В шапке виден статус агента и кнопка «Открыть настройки агента»; PowerShell с самим агентом запускается отдельно в Windows.
- Обзор папки при незапущенном агенте показывает 4 шага запуска и кнопку «Повторить».
- Несколько папок: в поле «Папки, которыми сможет управлять агент» укажи пути через `;` (команда запуска выставит `AZRAIL_ROOTS`). Агент называет папки по последнему звену пути (повтор: `-2`, `-3`), не больше 8. При двух и более папках в настройках появляется выбор «Активная папка»: смена применяется сразу, без перезапуска агента; чат, терминал и обзор папки работают в выбранной. Добавить новую папку в список можно только перезапуском агента.
- Задача несёт имя папки (`root`); сервер проверяет его по списку, который сообщил агент. Без `root` задача идёт в первую папку. Ограничения путей (`..`, симлинки, секреты) действуют в каждой папке отдельно.
- Обзор папки (Настройки → «Локальный агент»): проводник по корневой папке агента. Папки, переход вверх, хлебные крошки, просмотр файла (чтение, до 200 000 байт, показ первых 20 000 символов). Клик по записи подставляет путь в форму задачи. Корень задаётся переменной `AZRAIL_ROOT` при запуске агента; выше корня и вне её браузер ничего не показывает, чтобы выбрать другую папку, агента перезапускают с другим `AZRAIL_ROOT`. Команды выбираются из списка белого списка. Задачи обзора не попадают в список последних задач. После действия агент 30 секунд опрашивает очередь каждые 0,7 с (в покое раз в 3 с).
- Перед постановкой команды терминал и чат спрашивают `GET /api/agent/status`: если агент выключен или от него нет сигнала больше 15 секунд (`connected: false`), команда не создаётся, а ответ объясняет, что сделать. Пока агент выполняет команду, он не опрашивает очередь, поэтому вторая команда в это время получит то же сообщение.
- Режим разрешений агентов переключается в ⚙ → «Разрешения агентов» (только admin): «Доверять рабочей папке» (`trusted`) или «Спрашивать всё» (`ask`). Значение хранится в KV и важнее `AZRAIL_PERMISSION_MODE`; при сбое KV действует `ask`. Режим `autonomous` из интерфейса не включается: он ничего не расширяет, уровни 2–3 всегда с подтверждением.
- Защита: ответы агента в чате и запросы модели проходят `redactSecrets`; в цикле исправления файл с секретом или с сигналом подмены инструкций модели не отдаётся (`screenFiles`). Подробности — в модели угроз.
- Чтение — до 200 000 байт, запись — до 200 000 символов.
- Выключатель `AZRAIL_SWITCH_TOOLS=off` закрывает все маршруты агента.
- Страницы под входами: «открой https://сайт в моём браузере» (также «в моём хроме», «под моим входом» или «на компьютере» с полным адресом) ставит задачу `web`. Агент открывает страницу в отдельном профиле `~/.azrail-browser` (папка меняется через `AZRAIL_BROWSER_PROFILE`), не в основном Chrome, и возвращает адрес, заголовок и текст до 20 000 символов. Входы в сайты делаются один раз: `node scripts\local-agent\azrail-agent.mjs --browser-login` открывает обычный Chrome с этим профилем (без управления из программы, иначе Google отказывает во входе), войди и закрой окно. Нужны `npm install` в папке проекта и установленный Google Chrome (другой — `AZRAIL_BROWSER_CHANNEL`). `AZRAIL_BROWSER_HEADED=1` показывает окно при чтении. Клики, ввод и скриншоты на ПК — следующие этапы, каждое действие будет ждать «Разрешить».
- Привязка компьютера (без копирования ключа): агент без `AZRAIL_AGENT_TOKEN` просит привязку (`POST /api/agent/pair/start`), показывает код вида `1234-5678` и ждёт. Владелец вводит код в AZRAIL (`POST /api/agent/pair/approve`), агент получает постоянный ключ `azdev_…` один раз (`POST /api/agent/pair/poll`) и сохраняет его в `~/.azrail-agent.json` (`AZRAIL_DEVICE_FILE` меняет путь). Код живёт 10 минут, после 5 ошибок сгорает, новый запрос не чаще раза в 5 секунд. Один компьютер: новая привязка заменяет прежнюю, `POST /api/agent/pair/forget` отвязывает и выключает доступ. Постоянный ключ сам ничего не открывает: задачи отдаются, только пока открыто окно «Включить на 1 час». Без окна агент отвечает `idle` и ждёт, раз в 5 секунд. Если сервер отвязал компьютер (401), агент стирает файл и предлагает привязку заново. Старый способ (`AZRAIL_AGENT_TOKEN`) работает как прежде.
- Файлы для двойного клика в корне репозитория (PowerShell не нужен): `Start-Azrail-Agent.bat` — запускает агента в своей папке (адрес AZRAIL зашит, переопределяется переменной `AZRAIL_URL`), перед стартом тихо делает `git pull --ff-only`, при первом запуске сам ставит зависимости; `Login-Sites.bat` — один раз войти в сайты в обычном Chrome; `Autostart-On.bat` / `Autostart-Off.bat` — ярлык запуска в автозагрузке Windows (свёрнутое окно). Файлы хранятся с CRLF (`.gitattributes`).
- Порядок для пользователя: двойной клик `Start-Azrail-Agent.bat` → в окне код → «Настройки → Агент на компьютере» → ввести код → «Подтвердить компьютер». Дальше достаточно «Включить на 1 час» в настройках или в карточке чата; ключ копировать не нужно. «Забыть компьютер» отвязывает его.
