# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/ed88de3f-a6fa-4951-93cd-d9184eb7ec0e

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Copy [env.example](env.example) to `.env.local`, then set `GEMINI_API_KEY` in the local copy
3. Run the app:
   `npm run dev`
